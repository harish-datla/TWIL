# Graph Traversal

Graphs model dependencies throughout an engine: scene hierarchies, render passes, asset imports, navmeshes, and AI behavior trees. This tutorial builds BFS and DFS, then derives topological sorting, strongly connected components, shortest paths, A*, and production pathfinding variants.

Time: ~55 min  
Level: Junior to mid  
Prerequisites: C++ or pseudocode, queues, stacks, and Big O.  
Phase: 11 · AI

## What you’ll be able to do

- Store graphs as adjacency lists, matrices, or edge lists.
- Write BFS and DFS without recursion-depth failures.
- Topologically order dependencies and identify cycles with SCCs.
- Find shortest paths with Dijkstra and admissible A* heuristics.
- Explain jump point search, hierarchical pathfinding, and Recast/Detour.

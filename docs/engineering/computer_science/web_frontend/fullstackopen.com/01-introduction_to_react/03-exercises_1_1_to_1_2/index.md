# Exercises 1.1–1.2: Course Information

[Back to Part 1](../index.md)

Build the Course Information application with Vite and React. First create the course, parts, and exercise totals; then refactor the application into `Header`, `Content`, `Part`, and `Total` components that receive their data through props.

Submit the completed application through the course submission system. The exercises are submitted as a part, so finish the exercises you intend to submit before marking Part 1 as complete.

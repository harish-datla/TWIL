# Full Stack Open

## Deep Dive Into Modern Web Development

[Start course](https://fullstackopen.com/en/)

Learn React, Redux, Node.js, MongoDB, GraphQL, TypeScript, React Native, CI/CD, containers, relational databases, and Next.JS through modern JavaScript-based web development.

The course focuses on single-page applications built with React and REST APIs built with Node.js.

## General information

Full Stack Open is a free, continuously updated course from the [University of Helsinki](https://www.helsinki.fi/en). It covers modern JavaScript web development from browser fundamentals through React, Node.js, databases, mobile applications, deployment, and Next.js.

The course is organized into a core course (Parts 0–5) and extension parts (Parts 6–14). You can study the material online, complete exercises and projects, and optionally earn a certificate and university credits.

## Before you start

You should be comfortable with basic programming concepts and have access to:

- Chrome or Firefox Developer Edition
- Git
- VS Code or another editor
- Node.js 24 or newer, with npm and npx

The course is designed to be followed in order. Read [Part 0](00-fundamentals_of_web_apps/index.md) first, since it explains the workflow, prerequisites, exercises, and how the course is assessed.

## Course structure and credits

The core course consists of Parts 0–5 and contains 116 exercises. Completing the required exercise threshold earns five credits in course CSM141081:

| Completed exercises | Grade | Credits |
| ---: | ---: | ---: |
| 72 | 1 | 5 |
| 83 | 2 | 5 |
| 94 | 3 | 5 |
| 105 | 4 | 5 |
| 116 | 5 | 5 |

The extension parts carry additional credits: Parts 6–9 and 11–14 carry one credit each, while Part 10 carries two credits. Check the current part instructions for the exact exercise and submission requirements.

## Studying, submissions, and help

Exercises are completed locally and submitted through the course submission system. Some parts include projects that build on earlier work. The course also supports an exam and certificate process for students who want official University of Helsinki credit; follow the current instructions on the course site because requirements can change.

For questions and peer support, join the [Full Stack Open Discord community](https://study.cs.helsinki.fi/discord/join/fullstack). Read Part 0 and the course guidance before asking questions, and use the recommended format when requesting help.

## Course updates

Full Stack Open no longer publishes separate yearly versions. The course continues to evolve as new material is released. Recent updates include the Next.js, React Native, extension, state-management, core, TypeScript, CI/CD, containers, relational-database, and GraphQL modules.

You can contribute corrections and improvements through the course repository. Preserve the original authors’ attribution and the course license when sharing modified material.

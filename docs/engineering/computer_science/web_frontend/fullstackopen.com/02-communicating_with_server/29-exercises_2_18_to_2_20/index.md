# Exercises 2.18–2.20: Data for countries

[Back to Part 2](../index.md)

Build a country-search application using the REST Countries service. Show matching countries, allow a single country to be selected, display its details and flag, and add a weather report for its capital using an external weather API.

Keep API keys in environment variables and do not commit them to source control.

# Introduction to web accessibility

[Back to Junior](../index.md)

[Learning path](https://www.frontendmentor.io/learning-paths/introduction-to-web-accessibility-mXu-9PHVsd)

Understanding accessibility and creating accessible websites is crucial for front-end developers. This path introduces key concepts and provides challenges with accessibility considerations in each design.

## Prerequisites

A good understanding of HTML, CSS, and JavaScript is recommended. Earlier Frontend Mentor paths provide useful preparation.

## Learning outcomes

- Understand the importance of web accessibility
- Learn accessibility standards and guidelines
- Understand best practices for accessible development
- Practice using assistive technologies and tools
- Learn how to conduct accessibility tests
- Develop an accessibility mindset

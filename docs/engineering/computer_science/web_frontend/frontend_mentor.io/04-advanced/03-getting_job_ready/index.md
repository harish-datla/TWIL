# Getting job ready

[Back to Advanced](../index.md)

[Learning path](https://www.frontendmentor.io/learning-paths/getting-job-ready-D1Oy0wCxWj)

This path provides tools for standing out in the job market and making a strong impression with potential employers.

## Prerequisites

Completing the other learning paths first is ideal because it provides more project experience, but this path can be taken at any stage.

## Learning outcomes

- Build an effective online professional presence
- Find web development opportunities
- Develop essential soft skills
- Prepare for technical interviews
- Understand workplace dynamics and professional workflows

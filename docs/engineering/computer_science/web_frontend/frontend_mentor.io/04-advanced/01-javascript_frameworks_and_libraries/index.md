## Prerequisites

A good understanding of JavaScript fundamentals is recommended. Start with the [JavaScript fundamentals learning path](https://www.frontendmentor.io/learning-paths/javascript-fundamentals-oR7g6-mTZ-) if needed.

## Learning outcomes

- Understand concepts behind popular JavaScript frameworks
- Understand the modern JavaScript ecosystem
- Grasp component-based architecture
- Learn state-management patterns
- Learn how to work with forms
- Implement routing for multi-page projects

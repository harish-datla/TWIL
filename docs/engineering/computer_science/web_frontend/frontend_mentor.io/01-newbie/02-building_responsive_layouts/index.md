# Building responsive layouts

[Back to Newbie](../index.md)

[Learning path](https://www.frontendmentor.io/learning-paths/building-responsive-layouts--z1qCXVqkD)

A crucial part of modern front-end development is making web pages look good on various device sizes. These challenges develop the skills needed to build layouts that work across all devices.

## Prerequisites

A basic understanding of HTML and CSS fundamentals is recommended. The [Getting started on Frontend Mentor](https://www.frontendmentor.io/learning-paths/getting-started-on-frontend-mentor-XJhRWRREZd) path is a useful prerequisite.

## Learning outcomes

- Understand responsive design principles
- Master CSS media queries
- Incorporate responsive media and fluid typography
- Learn to use Flexbox and CSS Grid
- Start cross-browser and cross-device testing

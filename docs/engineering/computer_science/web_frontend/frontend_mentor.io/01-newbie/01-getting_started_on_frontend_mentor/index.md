# Getting started on Frontend Mentor

[Back to Newbie](../index.md)

[Learning path](https://www.frontendmentor.io/learning-paths/getting-started-on-frontend-mentor-XJhRWRREZd)

These projects help you find your feet on the Frontend Mentor platform and gain experience building small HTML and CSS projects.

## Prerequisites

Basic HTML and CSS knowledge is recommended. The path also links to resources for learning the fundamentals.

## Learning outcomes

- Get up and running on Frontend Mentor
- Set up your development environment
- Learn Git and GitHub basics
- Learn to work with a design file
- Build your first projects

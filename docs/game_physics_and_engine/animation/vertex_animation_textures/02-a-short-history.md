# A Short History of Putting Animation in a Texture

The idea predates the name VAT. NVIDIA’s 2007 skinned-instancing work read bone matrices from textures for thousands of characters. Houdini later standardized soft, rigid, fluid, and sprite exporters. Modern engines use VAT beside skeletal animation: rigs for characters needing blending, IK, ragdolls, and interaction; VAT for crowds and baked simulations.

Tools now include Unreal’s AnimToTexture, SideFX Labs VAT, OpenVAT, and integrations for Unity, Godot, and other engines. VAT is a data-layout technique, not an engine-specific animation system.

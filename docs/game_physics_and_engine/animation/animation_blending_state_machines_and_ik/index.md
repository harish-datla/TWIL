# Animation: Blending, State Machines & IK

This module covers the systems upstream of the skeletal-animation palette: state machines, blend spaces, layered and additive animation, motion matching, and inverse kinematics.

Time: ~80 min  
Level: Senior  
Prerequisites: The Skeletal Animation module and Behavior Trees.  
Stack: C++ & Rust

## What you’ll be able to do

- Build state-machine transitions with timed cross-fades and inertialization.
- Compute 1D and 2D blend-space weights.
- Layer upper-body actions over locomotion with masks and additive deltas.
- Build and search motion-matching feature databases.
- Implement FABRIK and combine raycasts, pelvis adjustment, and two-bone IK for foot placement.
